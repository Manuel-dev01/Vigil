# AI usage

Vigil is built with an AI coding agent (Claude Code) working with the team. This log records the notable work the agent did and what the humans reviewed or decided. Entries are dated (UTC).

**How we work with AI, in short.**
- **Two humans, two coding agents** (one each).
  - The humans set the design rules (no classical-key authority anywhere, evidence for every claim, testnet only) and decide anything that moves value, creates a key or is published.
  - The agents write code, run the chain checks and keep the evidence ledger.
- **Guardrails:**
  - every on-chain action is simulated first and needs the human's explicit word;
  - secrets stay in files and never enter a prompt or a log;
  - a secret scanner runs before every push;
  - no agent opens an EVM window on the creator's or a watchtower's key.
- **Agents checking agents.**
  - Each agent re-ran the other's results before building on them (Spike C).
  - Subagents ported the validator to four languages, and the lead agent re-ran every language's CI.
  - On 24 Nov six subagents attacked the whole project from different angles. The lead agent reproduced their findings before fixing them (THREAT_MODEL §12 F6–F10).
- **Mistakes caught, and what changed:**
  - the standby sequencer's off-by-one (found in the drill's logs);
  - a test that caught the SDK's signer unable to encode inbox posts before it reached production;
  - on 24 Nov, a shell command written by the agent that ran a deploy step from the wrong folder (undone within minutes; the agent now quotes every shell heredoc).
